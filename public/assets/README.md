# Recursos locales

## Video

- `video/apertura-ia-2023.mp4`: comparación histórica suministrada por el presentador.
- `video/apertura-ia-2026.mp4`: video generado con Seedance, según confirmación del presentador.

## Audio

- `audio/audio-directora-simulado.wav`: mensaje ficticio que abre el primer capítulo.
- `audio/votacion-abierta.wav`: señal opcional al entrar en una decisión.
- `audio/revelacion.mp3`: señal opcional al revelar una consecuencia.

Las señales se reproducen únicamente tras una interacción del presentador y pueden silenciarse desde la barra de controles.
